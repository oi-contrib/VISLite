Hermite Hermite

引入 Import 

import { Hermite } from "vislite"

语法 Syntax 

let hermite = new Hermite(u = 0.5)

其中u表示张弛系数。 Where u represents the tension coefficient.

setP setP

设置点的位置和斜率： Set point positions and slopes: 

hermite.setP(x1, y1, x2, y2, s1, s2)
  1. x1，y1：左边点的位置 x1, y1: Position of the left point
  2. x2，y2：右边点的位置 x2, y2: Position of the right point
  3. s1，s2：两个点的斜率 s1, s2: Slopes at both points

use use

根据x值返回y值： Return y value based on x: 

hermite.use(x)

配置画笔 Configure Painter

可配置项 Configurable Options 

painter.config({
    // 填充色或图案
    // fill color or pattern
    "fillStyle": 'black',

    // 轮廓色或图案
    // stroke color or pattern
    "strokeStyle": 'black',

    // 线条宽度(单位px，下同)
    // line width (in px, same below)
    "lineWidth": 1,

    // 线的端点类型
    // line cap: "butt", "round", "square" (1.2.0+)
    "lineCap": "butt",

    // 线的拐角连接方式
    // line join: "miter", "bevel", "round" (1.2.0+)
    "lineJoin": "miter",

    // 设置线条虚线
    // line dash pattern
    "lineDash": [],

    // 文字水平对齐方式
    // text horizontal alignment: "left", "center", "right"
    "textAlign": 'left',

    // 文字垂直对齐方式
    // text vertical alignment: "middle", "top", "bottom"
    "textBaseline": 'middle',

    // 文字大小
    // font size
    "fontSize": 16,

    // 字体，默认"sans-serif"
    // font family, default "sans-serif"
    "fontFamily": "sans-serif",

    // 圆弧开始端闭合方式
    // arc start cap: "butt", "round", "-round" (-round 0.3.0+)
    "arcStartCap": 'butt',

    // 圆弧结束端闭合方式
    // arc end cap
    "arcEndCap": 'butt',

    // 矩形圆角半径
    // rectangle corner radius (1.3.0+)
    "rectRadius": Array<number>
});

渐变色 Gradient Colors

0.5.2 新增 Added in 0.5.2

上述配置颜色的地方，除了可以配置纯色外，还可以使用下面的渐变色。 In addition to solid colors, you can also use gradient colors.

线性渐变 Linear Gradient

使用画笔的createLinearGradient创建线性渐变对象，四个参数分别表示渐变的起点P(x1, y1)和终点P(x2, y2)： Create a linear gradient with start point P(x1, y1) and end point P(x2, y2): 

    let gradient = painter.createLinearGradient(x1, y1, x2, y2)
温馨提示：画笔上述参数的单位是%（下同）。 Note: The painter parameters are in % (same below).

环形渐变 Radial Gradient

使用画笔的createRadialGradient创建环形渐变对象，三个参数分别表示渐变的圆心P(cx, cy)和半径r： Create a radial gradient with center P(cx, cy) and radii r1, r2: 

    let gradient = painter.createRadialGradient(cx, cy, r1, r2)
温馨提示：渐变的起点是圆心。 Note: The starting point of the gradient is the center.

设置与使用 Setup and Usage

设置渐变范围以后，你需要在渐变范围中添加渐变色，可以添加任意多个： After setting gradient range, add gradient colors: 

    gradient.setColor(deep, color)

上述deep取值为闭区间[0, 1]，color可以是任意合法的颜色值。 deep takes a value in the closed interval [0, 1], and color can be any valid color value.

渐变如何使用，直接调用渐变的value方法即可： To use the gradient, call the gradient's value method: 

painter.config({
    "fillStyle": gradient.value()
})

如上面，我们给画笔设置填充色就是使用了我们刚刚获取的渐变色。 As shown above, we set the painter's fill color using the gradient we just obtained.

重置 Reset

1.2.0 新增 Added in 1.2.0

对画笔的配置重置为默认值（参数config可选，用于覆盖默认值，1.8.0新增）： Reset painter configuration to defaults: 

painter.reset(config={})

基础方法 Basic Methods

标记应用节点 Set Active Element 

painter.useEl(el)

获取当前应用的节点 Get Active Element 

let el = painter.getEl()

追加节点 Append Element 

painter.appendEl(el, context)
  • el：必输，节点或字符串，字符串的话表示节点名称； el: required, element or string (element name);
  • context：可选，节点，表示追加位置，默认根svg。 context: optional, append position, default root SVG.

追加绘制板 Append Board 

painter.appendBoard(el, context)
  • el：必输，节点或字符串，字符串的话表示需要绘制对应什么内容； el: required, element or string for content;
  • context：可选，节点，表示追加位置，默认根svg。 context: optional, append position, default root SVG.

删除当前维护的节点 Remove Element 

painter.remove()

设置或获取节点属性 Set/Get Attribute 

painter.attr(params)

绑定事件 Bind Event 

painter.bind(eventType, callback)

画笔方法 Painter Methods

文字 Text

在点(x, y)处绘制填充的文字text；deg表示文字旋转角度，可选： Draw filled text at point (x, y); deg is the rotation angle (optional): 

painter.fillText(text, x, y, deg)
除非特别说明，角度全部采用角度制。 Unless otherwise specified, all angles are in degrees.

在点(x, y)处绘制轮廓的文字text；deg表示文字旋转角度，可选： Draw stroked text at point (x, y); deg is the rotation angle (optional): 

painter.strokeText(text, x, y, deg)

在点(x, y)处绘制轮廓并填充的文字text；deg表示文字旋转角度，可选： Draw filled and stroked text at point (x, y); deg is the rotation angle (optional): 

painter.fullText(text, x, y, deg)

弧 Arc

以(cx, cy)为圆心，内外半径分别是r1和r2，从角度beginDeg开始，跨越角度deg，绘制填充圆弧： Draw filled arc with center (cx, cy), radii r1/r2, from beginDeg spanning deg: 

painter.fillArc(cx, cy, r1, r2, beginDeg, deg)

和fillArc方法类似，只不过绘制的是轮廓圆弧： Similar to fillArc, draws stroked arc: 

painter.strokeArc(cx, cy, r1, r2, beginDeg, deg)

和fillArc方法类似，只不过绘制的是轮廓并填充圆弧： Similar to fillArc, draws filled and stroked arc: 

painter.fullArc(cx, cy, r1, r2, beginDeg, deg)

圆形 Circle

以(cx, cy)为圆心，半径r绘制填充圆形： Draw filled circle with center (cx, cy) and radius r: 

painter.fillCircle(cx, cy, r)

以(cx, cy)为圆心，半径r绘制轮廓圆形： Draw stroked circle with center (cx, cy) and radius r: 

painter.strokeCircle(cx, cy, r)

以(cx, cy)为圆心，半径r绘制轮廓并填充圆形： Draw filled and stroked circle with center (cx, cy) and radius r: 

painter.fullCircle(cx, cy, r)

矩形 Rectangle

以(x, y)为左上角，宽width，高height绘制填充矩形： Draw filled rectangle with top-left (x, y), width and height: 

    painter.fillRect(x, y, width, height);

以(x, y)为左上角，宽width，高height绘制轮廓矩形： Draw stroked rectangle with top-left (x, y), width and height: 

painter.strokeRect(x, y, width, height)

以(x, y)为左上角，宽width，高height绘制轮廓并填充矩形： Draw filled and stroked rectangle with top-left (x, y), width and height: 

painter.fullRect(x, y, width, height)

路径 Path

基于路径可以绘制几乎大部分图形，非常类似画笔在纸上划动。 Almost all shapes can be drawn using paths, like drawing with a brush.

基础 Basic

开始一段独立的路径： Start an independent path: 

painter.beginPath()

闭合当前路径，也就是路径首尾闭合： Close the current path (connect start and end): 

painter.closePath()

画笔移动到点(x, y)，此时笔离开了画布： Move the brush to point (x, y), the brush is now off the canvas: 

painter.moveTo(x, y)

画笔移动到点(x, y)，此时笔没有离开画布： Move the brush to point (x, y), the brush stays on the canvas: 

painter.lineTo(x, y)

以(cx, cy)为圆心，半径r，从角度beginDeg开始，跨越角度deg画弧，此时笔没有离开画布： Draw an arc with center (cx, cy), radius r, from beginDeg spanning deg, the brush stays on the canvas: 

painter.arc(cx, cy, r, beginDeg, deg)

把当前路径包裹的区域填充颜色： Fill the area enclosed by the current path: 

painter.fill()

把当前路径上色（轮廓线）： Stroke the current path: 

painter.stroke()

把当前路径画上轮廓线并填充颜色到当前路径所包裹的区域： Stroke and fill the current path: 

painter.full()

贝塞尔曲线 Bezier Curve

二次贝塞尔曲线到： Quadratic Bezier curve to: 

painter.quadraticCurveTo(cpx, cpy, x, y)
只有一个控制点p(cpx, cpy),画笔当前的位置和p(x, y)分别是起点和终点。 There is only one control point p(cpx, cpy). The brush's current position and p(x, y) are the start and end points respectively.

三次贝塞尔曲线到： Cubic Bezier curve to: 

painter.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y)
有两个控制点p(cp1x, cp1y)和p(cp2x, cp2y),画笔当前的位置和p(x, y)分别是起点和终点。 There are two control points p(cp1x, cp1y) and p(cp2x, cp2y). The brush's current position and p(x, y) are the start and end points respectively.

树布局 Tree Layout
0.4.1 新增 Added in 0.4.1

引入 Import 

import { TreeLayout } from "vislite"

语法 Syntax

通过传递一个配置项即可创建布局对象： Create a layout object by passing a configuration: 

let treeLayout = new TreeLayout(config)

其中config表示布局求解的原始数据格式，如果你数据的格式类似下面： Where config represents the original data format for layout calculation. If your data format is similar to the following: 

{
    name:"编程",
    children:[{
        name:"前端",
        children:[]
    },...]
}

则config可以不传递，直接使用默认值，否则就需要自己配置不满足默认格式的部分，具体config是一个json，可选属性如下： Then config can be omitted and defaults will be used. Otherwise, you need to configure the parts that don't match the default format. config is a JSON object with the following optional properties:

root

获取根结点的方法，以默认格式为例（下同）： Method to get the root node. Taking the default format as an example (same below): 

"root": function(initTree){
    return initTree
}

children

获取子结点的方法： Method to get child nodes: 

"children": function(parentTree, initTree){
    return parentTree.children
}

id

获取结点ID方法： Method to get node ID: 

"id": function(treedata){
    return treedata.name
}

方法 Methods

setOption

设置布局的行为： Set layout behavior: 

    treeLayout.setOption(option)

其中option应该是一个json，用以规范树图的行为，可选属性如下： Where option should be a JSON object to specify tree diagram behavior. Optional properties are as follows:

offsetX

水平方向隐藏结点偏差值，number类型，默认0。 Horizontal offset for hidden nodes, number type, default 0.

offsetY

垂直方向隐藏结点偏差值，number类型，默认0。 Vertical offset for hidden nodes, number type, default 0.

type

树图类型，string类型，默认plain，还可以设置成rect矩形树图、circle圆树。 Tree diagram type, string type, default 'plain'. Can also be 'rect' for rectangular tree or 'circle' for circular tree.

direction

设置成矩形树图（rect）时有效，表示树图方向，字符串类型，可选值为： Valid when type is 'rect', indicates tree direction, string type. Options are:

  • LR：默认值，表示从左往右的树； LR: Default, tree from left to right;
  • RL：表示从右往左的树； RL: Tree from right to left;
  • TB：表示从上往下的树； TB: Tree from top to bottom;
  • BT：表示从下往上的树。 BT: Tree from bottom to top.

x

树图x坐标，type不是plain时有效，表示树图根一侧的中间位置（圆树的话就是圆心位置），下同。 Tree x coordinate, valid when type is not 'plain'. Represents the center position of the root side (or center of circle for circular tree). Same below.

y

树图y坐标。 Tree y coordinate.

width

设置成矩形树图（rect）时有效，表示矩形宽。 Valid when type is 'rect', represents rectangle width.

height

设置成矩形树图（rect）时有效，表示矩形高。 Valid when type is 'rect', represents rectangle height.

radius

设置成圆树图（circle）时有效，表示圆树的半径。 Valid when type is 'circle', represents circle radius.

duration

切换时长，number类型，默认500（即0.5s）。 Transition duration, number type, default 500 (0.5s).

use

单纯的树图坐标计算： Simple tree coordinate calculation: 

    let tree = treeLayout.use(initTree, noOpens = {})
参数 noOpens 0.5.0 新增 Parameter noOpens added in 0.5.0

其中noOpens表示一个结点是打开还是闭合，比如我们有结点id分别为："node1"和"node2"，第一个打开第二个关闭，那么就可以传递： Where noOpens indicates whether a node is open or closed. For example, if we have nodes with IDs "node1" and "node2", where the first is open and the second is closed: 

// 由于默认值是false，因此node1其实不传递也可以
// Since default is false, node1 can be omitted
treeLayout.use(initTree, {
    node1: false,
    node2: true
})

bind

绑定新的数据和渲染方法： Bind new data and rendering method: 

treeLayout.bind(initTree, function(tree){
    // 绘制出树图
    // Draw the tree
}, noOpens = {})
参数 noOpens 0.5.0 新增 Parameter noOpens added in 0.5.0
温馨提示：上述形参tree的格式你可以点击 Note: You can click 进行查阅。 to view the data format.

unbind

解除绑定： Unbind: 

    treeLayout.unbind()

closeNode

闭合指定节点： Close specified node: 

    treeLayout.closeNode(id)

openNode

展开指定节点： Open specified node: 

    treeLayout.openNode(id)

toggleNode

闭合或展开指定节点： Toggle specified node: 

    treeLayout.toggleNode(id)

doUpdate

1.2.1 新增 Added in 1.2.1

主动触发绘制更新： Trigger draw update manually: 

    treeLayout.doUpdate()

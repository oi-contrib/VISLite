基础变换 Basic Transformations

旋转 Rotate

引入 Import 

import { rotate } from "vislite"

语法 Syntax

点（x,y）围绕中心（cx,cy）旋转deg度： Rotate point (x,y) around center (cx,cy) by deg degrees: 

let p = rotate(cx, cy, deg, x, y)

移动 Move

0.5.2 新增 Added in 0.5.2

引入 Import 

import { move } from "vislite"

语法 Syntax

点（x,y）沿着向量（ax,ay）方向移动距离d： Move point (x,y) along vector (ax,ay) by distance d: 

let p = move(ax, ay, d, x, y)

缩放 Scale

0.5.2 新增 Added in 0.5.2

引入 Import 

import { scale } from "vislite"

语法 Syntax

点（x,y）围绕中心（cx,cy）缩放times倍： Scale point (x,y) around center (cx,cy) by times: 

let p = scale(cx, cy, times, x, y)

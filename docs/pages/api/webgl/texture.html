纹理 Texture
0.3.0 新增 Added in 0.3.0

引入 Import 

    import { Texture } from 'vislite'

语法 Syntax

获取纹理实例： Get texture instance: 

    let texture = new Texture(painter, type, unit)

其中参数解释如下： Parameters explained as follows:

  1. painter：WebGLRenderingContext 类型 type
  2. type：string 类型，可以是"2d"或"cube"，分别表示是二维纹理还是立方纹理 type, can be "2d" or "cube", representing 2D texture or cube texture respectively
  3. unit：number 类型，表示纹理单元，默认0 type, represents texture unit, default 0

方法 Methods

useImage

链接图片资源(单一)，表示纹理图片，TexImageSource类型： Link single image resource, representing texture image, TexImageSource type: 

    texture.useImage(image)

useCube

链接图片资源（多张）： Link multiple image resources: 

    texture.useCube(images, width, height)

其中参数解释如下： Parameters explained as follows:

  1. images： 纹理图片集，是一个数组，里面的元素是TexImageSource类型 Texture image set, an array where elements are of type TexImageSource
  2. width： 图片宽 Image width
  3. height： 图片高 Image height

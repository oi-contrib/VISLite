着色器 Shader
0.3.0 新增 Added in 0.3.0

引入 Import 

    import { Shader } from 'vislite'

语法 Syntax

传递一个WebGLRenderingContext类型的参数painter即可获取着色器实例： Pass a parameter painter of type WebGLRenderingContext to get the shader instance: 

let shader = new Shader(painter)

属性 Properties

program

着色器程序。 Shader program.

方法 Methods

use

使得当前的着色器程序启用： Enable the current shader program: 

    shader.use()
温馨提示：需要在编译compile完成后再调用这个方法。 Note: This method should be called after compile is completed.

compile

编译具体的着色器程序，需要传递的是两个参数，分别是顶点着色器和片段（元）着色器的字符串代码： Compile the specific shader program. Two parameters need to be passed: the vertex shader and fragment shader source code strings: 

    shader.compile(vshaderSource, fshaderSource)

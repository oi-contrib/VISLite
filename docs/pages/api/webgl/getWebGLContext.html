语法 Syntax

获取画笔实例，其中el就是挂载点，比如一个div： Get painter instance, where el is the mount point, such as a div: 

    let painter = getWebGLContext(el, scale, mode)

其中参数解释如下： Parameters explained as follows:

  1. el： 页面挂载点，比如DIV节点 Page mount point, such as DIV node
  2. scale： 画布缩放倍数，可选，默认1 Canvas scale ratio, optional, default 1
  3. mode： 设置画布缩放模式，可选（v0.8.0开始支持） Set canvas scale mode, optional (supported from v0.8.0)

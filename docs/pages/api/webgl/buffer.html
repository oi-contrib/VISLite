缓冲区 Buffer
0.3.0 新增 Added in 0.3.0

引入 Import 

    import { Buffer } from 'vislite'

语法 Syntax

获取缓冲区实例： Get buffer instance: 

    let buffer = new Buffer(painter, isElement)

其中参数解释如下： Parameters explained as follows:

  1. painter：WebGLRenderingContext 类型 type
  2. isElement：boolean 类型，默认false，表示不是索引缓冲区 type, default false, indicates not an index buffer

方法 Methods

use

使用这个缓冲区对象： Use this buffer object: 

    buffer.use()
温馨提示：应该先于写入write和分配divide。 Note: Should be called before write and divide.

write

写入数据，数据data类型可以是 Uint8Array | Int16Array | Uint16Array | Int32Array | Uint32Array | Float32Array： Write data. Data type can be Uint8Array | Int16Array | Uint16Array | Int32Array | Uint32Array | Float32Array: 

    buffer.write(data)

divide

分配使用 Allocate for use 

    buffer.divide(location, size, stride, offset)

其中参数解释如下： Parameters explained as follows:

  1. location：number 类型，表示变量位置 type, represents variable location
  2. size：number 类型，表示一个数据的长度 type, represents length of one data
  3. stride：number 类型，表示一组数据的长度(可能包含多组) type, represents length of one set of data (may contain multiple sets)
  4. offset：number 类型，表示读取位置偏移，可选，默认0 type, represents read position offset, optional, default 0

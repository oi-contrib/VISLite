Cardinal Cardinal

引入 Import 

import { Cardinal } from "vislite"

语法 Syntax 

let cardinal = new Cardinal(t = 0)

参数t用于调整曲线走势，默认数值t=0，分水岭t=-1，|t-(-1)|的值越大，曲线走势调整的越严重。 Parameter t is used to adjust the curve shape. Default is t=0, watershed is t=-1. The larger |t-(-1)| is, the more severe the curve adjustment.

setP setP

设置点的位置： Set point positions: 

cardinal.setP(points)

参数格式：[[x1, y1], [x2, y2], ... ]，至少两个点。 Parameter format: [[x1, y1], [x2, y2], ... ], at least two points.

use use

根据x值返回y值： Return y value based on x: 

cardinal.use(x)

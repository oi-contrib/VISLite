立方体运算 Geometry Operations
0.5.0 新增 Added in 0.5.0

引入 Import 

import { Geometry } from 'vislite'

语法 Syntax 

let geometry = new Geometry(option)

返回立方体对象，其中option是一个json，可选，其属性如下： Returns a geometry object. Option is an optional JSON with the following properties:

属性名 Property 类型 Type 默认值 Default 说明 Description
precision number 0.1 精度 Precision
normal boolean false 是否需要法向量 Whether normal vector is needed

修改配置 Modify Configuration

你创建对象的时候的属性值，后续都可以通过下面方法修改： The property values set when creating the object can be modified later using the following method: 

    geometry.config(option)

辅助方法 Helper Methods

0.8.0 新增 Added in 0.8.0

计算切割份数 Calculate Split Count

根据圆半径和跨越弧度获取切割份数： Get the number of segments based on circle radius and arc span: 

let num = geometry.splitNum(radius, deg = Math.PI * 2)

物体方向转换 Object Direction Transformation

返回一个点变换方法，变换按照射线(x1, y1, z1)旋转到(x2 - x1, y2 - y1, z2 - z1)方向进行： Returns a point transformation method that rotates along the ray from (x1, y1, z1) to (x2 - x1, y2 - y1, z2 - z1): 

let rotateLine = geometry.rotateLine(x1, y1, z1, x2, y2, z2)

立方片段 Geometry Fragments

0.8.0 新增 Added in 0.8.0

所有的方法返回的 All methods return 数据points 的格式都一致，都是number类型的数组，表示点的位置或法向量值（连线用"LINES"，其余用"TRIANGLES"）。 in the same format: an array of numbers representing point positions or normal vector values ("LINES" for connections, "TRIANGLES" otherwise).

棱柱水平部分 Prism Horizontal Part 

let points = geometry.prismHorizontal(x, y, z, radius, num, d, beginDeg = 0, deg = Math.PI * 2)

其中d表示水平是顶部(d = 1)还是底部(d = -1)。 Where d indicates top (d = 1) or bottom (d = -1).

棱柱垂直部分 Prism Vertical Part 

let points = geometry.prismVertical(x, y, z, radius, height, num, beginDeg = 0, deg = Math.PI * 2)

球体中的一瓣子 Sphere Segment

把一个球切割成num份，其中第index份的点数据： Divide a sphere into num segments and get point data for segment index: 

let points = geometry.sphereFragment(cx, cy, cz, radius, num, index)

立方体 Geometry Shapes

所有的方法返回的 All methods return 数据result 的格式都一致，如下： in the same format, as follows: 

Array<{
    name: string // 小块名称
    points: number[] // 点的位置或法向量值
    length: number // 点个数

    // 当前点应该使用何种方法绘制（为了简化后续绘制优化，连线用"LINES"，其余用"TRIANGLES"）
    method: "LINES" | "TRIANGLES"
}>

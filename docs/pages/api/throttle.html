节流函数 Throttle Function
0.4.1 新增 Added in 0.4.1

引入 Import 

import { throttle } from "vislite"

语法 Syntax 

let newFunction = throttle(function(){
    // todo
}, option)

返回一个节流函数，具体的行为受第二个参数option控制，option是一个json，可选，其属性如下： Returns a throttled function. The behavior is controlled by the second parameter option, which is an optional JSON with the following properties:

属性名 Property 类型 Type 默认值 Default 说明 Description
time number 200 节流时长，单位毫秒 Throttle duration in milliseconds
keep boolean false 是否持续节流，如果设置true，那个在一个持续时间内函数只会最后执行一次 Whether to keep throttling. If set to true, the function will only execute once at the end of the duration
opportunity string end 执行时机，可选值为：begin（开始触发）、end（结束触发）、wide（第一次开始触发，其余结束触发） Execution timing. Options: begin (trigger at start), end (trigger at end), wide (first at start, rest at end)

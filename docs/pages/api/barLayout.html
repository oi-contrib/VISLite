直方布局 Bar Layout
1.4.0 新增 Added in 1.4.0

引入 Import 

import { BarLayout } from "vislite"

语法 Syntax

通过传递一个配置项即可创建布局对象： Create a layout object by passing a configuration: 

let barLayout = new BarLayout(config)

其中config表示布局求解的原始数据格式，如果你数据的格式类似下面： Where config defines the raw data format. If your data is formatted like:

一维 One-dimensional 

{
    category: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'],
    data: [120, 200, 150, 80, 70, 110, 130]
}

二维 Two-dimensional 

{
    category: ['一月', '二月', '三月'],
    value: [{
        name: "City Alpha",
        data: [165, 170, 30]
    }, {
        name: "City Beta",
        data: [150, 105, 110]
    }, {
        name: "City Gamma",
        data: [220, 82, 63]
    }]
}

则config可以不传递，直接使用默认值，否则就需要自己配置不满足默认格式的部分，具体config是一个json，可选属性如下： config can be omitted to use defaults. Otherwise, configure the non-standard parts. config is a JSON with optional properties:

方法 Methods

setOption setOption

设置布局的行为： Set layout behavior: 

    barLayout.setOption(option)

其中option应该是一个json，用以规范直方图的行为，可选属性如下： Where option is a JSON to define bar chart behavior with optional properties:

x x

直方图左下角横坐标，number类型，默认50。 Bar chart bottom-left x-coordinate, number, default 50.

y y

直方图左下角纵坐标，number类型，默认350。 Bar chart bottom-left y-coordinate, number, default 350.

width width

直方图宽，number类型，默认400。 Bar chart width, number, default 400.

height height

直方图高，number类型，默认300。 Bar chart height, number, default 300.

category category

直方图分类刻度尺，字符串类型，可选值为： Bar chart category axis, string, options:

  • xAxis：默认值，表示x轴作为分类轴； xAxis: default, x-axis as category axis;
  • yAxis：表示y轴作为分类轴。 yAxis: y-axis as category axis.

duration duration

切换时长，number类型，默认200（即0.2s）。 Transition duration, number, default 200 (0.2s).

use use

单纯的直方图坐标计算： Pure bar chart coordinate calculation: 

    let bar = barLayout.use(initBar)

bind bind

绑定新的数据和渲染方法： Bind new data and rendering method: 

barLayout.bind(initBar, function(bar){
    // 绘制出直方图
})

unbind unbind

解除绑定： Unbind: 

    barLayout.unbind()

doUpdate doUpdate

主动触发绘制更新： Trigger drawing update manually: 

    barLayout.doUpdate()

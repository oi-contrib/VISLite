墨卡托投影 Mercator Projection
0.2.0 新增 Added in 0.2.0

引入 Import 

import { Mercator } from 'vislite'

使用 Usage

通过传递一个配置信息即可获取最终的实例函数： Pass configuration to get the final instance function: 

let mercator = new Mercator(scale = 7, center = [107, 36])

传递一个点的经纬度即可返回该点的绘图坐标： Pass longitude and latitude to get the drawing coordinates: 

// 特别需要注意，计算出来的位置是偏离中心点的距离
let d_xyz = mercator.use(longitude, latitude)

刻度尺 Ruler

引入 Import 

import { ruler } from "vislite"

语法 Syntax 

let rulerArray = ruler(maxValue, minValue, num)

返回一个数组，表示刻度尺上应该显示的刻度。 Returns an array representing the ticks to display on the ruler.

约束 Constraints

0.4.1 新增 Added in 0.4.1

此外，还可以约束上下界： In addition, you can constrain the upper and lower bounds: 

let rulerArray = ruler(maxValue, minValue, num, {
    max: number,
    min: number
})

你可以只传递max或min来约束上界或下界，也可以同时传递来约束上下界。 You can pass only max or min to constrain the upper or lower bound, or both to constrain both bounds.

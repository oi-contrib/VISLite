饼布局 Pie Layout
1.4.0 新增 Added in 1.4.0

引入 Import 

import { PieLayout } from "vislite"

语法 Syntax

通过传递一个配置项即可创建布局对象： Create a layout object by passing a configuration: 

let pieLayout = new PieLayout(config)

其中config表示布局求解的原始数据格式，如果你数据的格式类似下面： Where config defines the raw data format. If your data is formatted like: 

[
    { value: 1048, name: 'Search Engine' },
    ...
]

则config可以不传递，直接使用默认值，否则就需要自己配置不满足默认格式的部分，具体config是一个json，可选属性如下： config can be omitted to use defaults. Otherwise, configure the non-standard parts. config is a JSON with optional properties:

温馨提示：数据必须是一个数组。 Note: Data must be an array.

name name

获取条目名称的方法，以默认格式为例（下同）： Method to get item name, using default format as example: 

"name": function(pieData, initPie){
    return pieData.name
}

value value

获取条目值的方法： Method to get item value: 

"value": function(pieData, initPie){
    return pieData.value
}

方法 Methods

setOption setOption

设置布局的行为： Set layout behavior: 

    pieLayout.setOption(option)

其中option应该是一个json，用以规范饼图的行为，可选属性如下： Where option is a JSON to define pie chart behavior with optional properties:

cx cx

饼图圆心横坐标，number类型，默认200。 Pie center x-coordinate, number, default 200.

cy cy

饼图圆心纵坐标，number类型，默认200。 Pie center y-coordinate, number, default 200.

radius radius

饼图内外半，number数组类型，默认[50, 100]。 Inner and outer radii, number array, default [50, 100].

duration duration

切换时长，number类型，默认200（即0.2s）。 Transition duration, number, default 200 (0.2s).

use use

单纯的饼图坐标计算： Pure pie chart coordinate calculation: 

    let pie = pieLayout.use(initPie, hoverIndex = -1)

bind bind

绑定新的数据和渲染方法： Bind new data and rendering method: 

pieLayout.bind(initPie, function(pie){
    // 绘制出饼图
})
温馨提示：上述形参pie的格式你可以点击 Note: Click 进行查阅。 to view the pie data format.

unbind unbind

解除绑定： Unbind: 

    pieLayout.unbind()

setHover setHover

设置当前悬浮序号（-1表示取消悬浮）： Set current hover index (-1 to cancel): 

    pieLayout.setHover(hoverIndex)

doUpdate doUpdate

主动触发绘制更新： Trigger drawing update manually: 

    pieLayout.doUpdate()

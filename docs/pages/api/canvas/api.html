配置画笔 Configure Painter

可配置项 Configurable Options 

painter.config({
    // 填充色或图案
    // fill color or pattern
    "fillStyle": 'black',

    // 轮廓色或图案
    // stroke color or pattern
    "strokeStyle": 'black',

    // 线条宽度(单位px，下同)
    // line width (in px, same below)
    "lineWidth": 1,

    // 线的端点类型
    // line cap: "butt", "round", "square" (1.2.0+)
    "lineCap": "butt",

    // 线的拐角连接方式
    // line join: "miter", "bevel", "round" (1.2.0+)
    "lineJoin": "miter",

    // 设置线条虚线
    // line dash pattern
    "lineDash": [],

    // 文字水平对齐方式
    // text horizontal alignment: "left", "center", "right"
    "textAlign": 'left',

    // 文字垂直对齐方式
    // text vertical alignment: "middle", "top", "bottom"
    "textBaseline": 'middle',

    // 阴影的模糊系数，默认0
    // shadow blur, default 0
    "shadowBlur": 0,

    // 阴影的颜色
    // shadow color
    "shadowColor": "black",

    // 文字大小
    // font size
    "fontSize": 16,

    // 字体
    // font family
    "fontFamily": "sans-serif",

    // 字重
    // font weight
    "fontWeight": 400,

    // 字类型
    // font style
    "fontStyle": "normal",

    // 圆弧开始端闭合方式
    // arc start cap: "butt", "round", "-round" (-round 0.3.0+)
    "arcStartCap": 'butt',

    // 圆弧结束端闭合方式
    // arc end cap
    "arcEndCap": 'butt',

    // 矩形圆角半径
    // rectangle corner radius (1.3.0+)
    "rectRadius": Array<number>
})

渐变色 Gradient Colors

0.3.0 新增 Added in 0.3.0

上述配置颜色的地方，除了可以配置纯色外，还可以使用下面的渐变色。 In addition to solid colors, you can also use the following gradient colors for color configurations.

线性渐变 Linear Gradient

使用画笔的createLinearGradient创建线性渐变对象，四个参数分别表示渐变的起点P(x1, y1)和终点P(x2, y2)： Use the painter's createLinearGradient to create a linear gradient object. The four parameters represent the start point P(x1, y1) and end point P(x2, y2): 

    let gradient = painter.createLinearGradient(x1, y1, x2, y2)
温馨提示：画笔上述参数的单位是px（下同)。 Note: The painter parameters are in px (same below).

环形渐变 Radial Gradient

使用画笔的createRadialGradient创建环形渐变对象，三个参数分别表示渐变的圆心P(cx, cy)和半径r： Use the painter's createRadialGradient to create a radial gradient object. The three parameters represent the center P(cx, cy) and radii r1, r2: 

    let gradient = painter.createRadialGradient(cx, cy, r1, r2)
温馨提示：渐变的起点是圆心。 Note: The starting point of the gradient is the center.

角度渐变 Conic Gradient

1.2.0 新增 Added in 1.2.0

使用画笔的createConicGradient创建角度渐变对象，四个参数分别表示渐变的圆心P(cx, cy)、开始弧度beginDeg和跨越弧度deg： Use the painter's createConicGradient to create a conic gradient object. The four parameters represent the center P(cx, cy), start angle beginDeg, and span angle deg: 

    let gradient = painter.createConicGradient(cx, cy, beginDeg, deg)
温馨提示：跨越弧度deg可选，默认2PI。 Note: The span angle deg is optional, default 2PI.

设置与使用 Setup and Usage

设置渐变范围以后，你需要在渐变范围中添加渐变色，可以添加任意多个： After setting the gradient range, you need to add gradient colors within the range. You can add as many as you want: 

    gradient.setColor(deep, color)

上述deep取值为闭区间[0, 1]，color可以是任意合法的颜色值。 deep takes a value in the closed interval [0, 1], and color can be any valid color value.

渐变如何使用，直接调用渐变的value方法即可： To use the gradient, call the gradient's value method: 

painter.config({
    "fillStyle": gradient.value()
})

如上面，我们给画笔设置填充色就是使用了我们刚刚获取的渐变色。 As shown above, we set the painter's fill color using the gradient we just obtained.

重置 Reset

1.2.0 新增 Added in 1.2.0

对画笔的配置重置为默认值（参数config可选，用于覆盖默认值，1.8.0新增）： Reset the painter configuration to default values (config parameter is optional for overriding defaults, added in 1.8.0):

文字 Text

在点(x, y)处绘制填充的文字text；deg表示文字旋转角度，可选： Draw filled text at point (x, y); deg is the rotation angle (optional): 

painter.fillText(text, x, y, deg)
除非特别说明，角度全部采用弧度制。 Unless otherwise specified, all angles are in radians.

在点(x, y)处绘制轮廓的文字text；deg表示文字旋转角度，可选： Draw stroked text at point (x, y); deg is the rotation angle (optional): 

painter.strokeText(text, x, y, deg)

在点(x, y)处绘制轮廓并填充的文字text；deg表示文字旋转角度，可选： Draw filled and stroked text at point (x, y); deg is the rotation angle (optional): 

painter.fullText(text, x, y, deg)

多行文字 Multi-line Text

简单的理解就是设置了文本显示的宽以后，如果文本超过一行，会自动换行显示。 Simply put, if the text exceeds the specified width, it will automatically wrap to the next line.

0.2.0 新增 Added in 0.2.0

painter.fillTexts(contents, x, y, width, lineHeight, deg)

返回一个数字，表示实际文字所占的高。 Returns a number representing the actual height of the text.

弧 Arc

以(cx, cy)为圆心，内外半径分别是r1和r2，从弧度beginDeg开始，跨越弧度deg，绘制填充圆弧： Draw a filled arc with center (cx, cy), inner and outer radii r1 and r2, starting from beginDeg with span deg: 

painter.fillArc(cx, cy, r1, r2, beginDeg, deg)

和fillArc方法类似，只不过绘制的是轮廓圆弧： Similar to fillArc, but draws a stroked arc: 

painter.strokeArc(cx, cy, r1, r2, beginDeg, deg)

和fillArc方法类似，只不过绘制的是轮廓并填充圆弧： Similar to fillArc, but draws a filled and stroked arc: 

painter.fullArc(cx, cy, r1, r2, beginDeg, deg)

圆形 Circle

以(cx, cy)为圆心，半径r绘制填充圆形： Draw a filled circle with center (cx, cy) and radius r: 

painter.fillCircle(cx, cy, r)

以(cx, cy)为圆心，半径r绘制轮廓圆形： Draw a stroked circle with center (cx, cy) and radius r: 

painter.strokeCircle(cx, cy, r)

以(cx, cy)为圆心，半径r绘制轮廓并填充圆形： Draw a filled and stroked circle with center (cx, cy) and radius r: 

painter.fullCircle(cx, cy, r)

矩形 Rectangle

以(x, y)为左上角，宽width，高height绘制填充矩形： Draw a filled rectangle with top-left corner at (x, y), width and height: 

    painter.fillRect(x, y, width, height);

以(x, y)为左上角，宽width，高height绘制轮廓矩形： Draw a stroked rectangle with top-left corner at (x, y), width and height: 

painter.strokeRect(x, y, width, height)

以(x, y)为左上角，宽width，高height绘制轮廓并填充矩形： Draw a filled and stroked rectangle with top-left corner at (x, y), width and height:

路径 Path

基于路径可以绘制几乎大部分图形，非常类似画笔在纸上划动。 Almost all shapes can be drawn based on paths, similar to drawing with a brush on paper.

基础 Basic

开始一段独立的路径： Start an independent path: 

painter.beginPath()

闭合当前路径，也就是路径首尾闭合： Close the current path (connect start and end): 

painter.closePath()

画笔移动到点(x, y)，此时笔离开了画布： Move the brush to point (x, y), the brush is now off the canvas: 

painter.moveTo(x, y)

画笔移动到点(x, y)，此时笔没有离开画布： Move the brush to point (x, y), the brush stays on the canvas: 

painter.lineTo(x, y)

以(cx, cy)为圆心，半径r，从弧度beginDeg开始，跨越弧度deg画弧，此时笔没有离开画布： Draw an arc with center (cx, cy), radius r, starting from beginDeg with span deg, the brush stays on the canvas: 

painter.arc(cx, cy, r, beginDeg, deg)

把当前路径包裹的区域填充颜色： Fill the area enclosed by the current path: 

painter.fill()

把当前路径上色（轮廓线）： Stroke the current path: 

painter.stroke()

把当前路径画上轮廓线并填充颜色到当前路径所包裹的区域： Stroke and fill the current path: 

painter.full()

贝塞尔曲线 Bezier Curve

二次贝塞尔曲线到： Quadratic Bezier curve to: 

painter.quadraticCurveTo(cpx, cpy, x, y)
只有一个控制点p(cpx, cpy),画笔当前的位置和p(x, y)分别是起点和终点。 There is only one control point p(cpx, cpy). The brush's current position and p(x, y) are the start and end points respectively.

三次贝塞尔曲线到： Cubic Bezier curve to: 

painter.bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y)
有两个控制点p(cp1x, cp1y)和p(cp2x, cp2y),画笔当前的位置和p(x, y)分别是起点和终点。 There are two control points p(cp1x, cp1y) and p(cp2x, cp2y). The brush's current position and p(x, y) are the start and end points respectively.

区域管理 Region Management

有时候，我们可能需要和绘制的图表进行交互，比如点击的时候，需要知道点击的是哪个区域，就可以借助下面的方法： Sometimes we need to interact with drawn charts, for example, when clicking, we need to know which region was clicked. You can use the following methods:

设置区域 Set Region

每次绘制一个区域前修改一下区域的名称，那么绘制的内容就会被记录起来： Set the region name before drawing, and the drawn content will be recorded: 

painter.setRegion(regionName)

获取区域 Get Region

比如点击了画布后，传递点击的位置，就可以返回当前位置所在区域的名称： Pass the click position to get the region name at that location: 

painter.getRegion(x, y).then((regionName) => {
    // todo
})

区域模式 Region Mode

是否绘制的内容只需要进行区域记录： Whether drawn content only needs to be recorded in the region: 

painter.onlyRegion(flag)

如果flag为true，那么后续所有的操作都不会同步到画布中，只会被区域记录，重新设置成false即可退出区域模式。 If flag is true, all subsequent operations will not be synchronized to the canvas, only recorded in the region. Set to false to exit region mode.

绘制模式 Draw Mode

1.0.0 新增 Added in 1.0.0

是否只进行绘制而不影响区域相关操作： Whether to only draw without affecting region operations: 

painter.onlyView(flag)

如果flag为true，那么后续所有的操作都不会同步到区域中，只会被呈现到画布中，重新设置成false即可退出绘制模式。 If flag is true, all subsequent operations will not be synchronized to the region, only rendered to the canvas. Set to false to exit draw mode.

原生画笔 Native Painter

0.2.0 新增 Added in 0.2.0

也就是canvas上的原生画笔，没有经过任何修饰的： This is the native painter on canvas, without any modifications: 

let ctx = painter.getContext(isRegion = false)

可以传递一个参数isRegion，默认false表示返回的是画布的，如果设置true返回的就是区域的。 Pass isRegion parameter, default false returns the canvas context, true returns the region context.

如何配合区域控制？ How to Work with Region Control?

如果你使用此处的原生画笔绘制，默认是无法自动与区域管理机制配合运行的，不过，你可以手动使其一致。 If you draw with this native painter, it won't automatically work with the region management mechanism by default. However, you can manually make them consistent.

比如你用下面的方法获取了画布的原生画笔并绘制了一个矩形： For example, you get the canvas's native painter and draw a rectangle: 

let ctx = painter.getContext()
ctx.fillRect(0, 0, 100, 50)

那么，你如果给画布添加了点击事件，并使用setRegion设置区域名称，然后在点击的时候通过getRegion来获取是否点击在这个矩形上的。 If you add a click event to the canvas, set the region name with setRegion, and then use getRegion to check if the click was on this rectangle.

非常不幸，你会发现机制失灵了。 Unfortunately, you will find that the mechanism doesn't work.

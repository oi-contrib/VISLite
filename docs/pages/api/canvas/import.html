引入和初始化 Import and Initialize

Web端 Web 

import { Canvas } from 'vislite'

// 获取画笔
let painter = new Canvas(el)

其中el是画布的挂载点，比如可以是一个DIV节点。 Where el is the canvas mount point, such as a DIV node.

配置 Configuration

创建画笔的时候，你还可以传递一个参数来进行更精细的控制： When creating the painter, you can also pass parameters for more precise control: 

let painter = new Canvas(el, {

    // 数字类型，默认2，表示缩放倍率（v1.5.0开始支持）
    // number type, default 2, represents scale ratio
    "scale": number

    // Boolean类型，默认true，表示是否支持区域管理（v0.4.1开始支持）
    // boolean type, default true, whether to support region management
    "region": boolean,

    // Boolean类型，默认false，如果多次获取画布颜色（例如：painter.getColor方法）可以开启（v0.6.0开始支持）
    // boolean type, default false, enable if you frequently get canvas color
    "willReadFrequently": boolean
})

画布大小 Canvas Size

1.0.0 新增 Added in 1.0.0

默认情况下，画布大小都是自动嗅探的，而对于不显示的画布，可以进行设置： By default, canvas size is auto-detected. For invisible canvases, you can set it manually: 

let painter = new Canvas(el, {}, width, height)

uni-app uni-app

目前只支持 "浏览器"、"微信小程序"、"支付宝小程序" 等端。 Currently only supports "Browser", "WeChat Mini Program", "Alipay Mini Program" and other platforms.
若需要支持更多端，可以留言告诉我们进行兼容扩展改造！ If you need to support more platforms, leave us a message!

我们提供的是一个uni-app组件，引入以后需要进行注册： We provide a uni-app component that needs to be registered after import: 

import uiCanvas from 'vislite/uni-app/ui-canvas.vue'

export default {
    components:{
        uiCanvas
    }
};

注册完毕就可以在页面中使用了： After registration, you can use it in the page: 

    <ui-canvas ref='mycanvas' :width='400' :height='300'></ui-canvas>

然后获取画笔： Then get the painter: 

this.$refs.mycanvas.fetch().then(painter => {
    // todo
})

此时，你就可以用这只画笔绘制你想要的内容了。 Now you can use this painter to draw whatever you want.

稍微特殊一点的是，每次全部绘制完毕以后，都需要额外调用下面的方法刷新画布： A special note: each time after all drawing is complete, you need to call the following method to refresh the canvas: 

painter.draw(reserve, callback)
上述方法参数(reserve, callback) 0.4.1 新增 Parameters (reserve, callback) added in 0.4.1

均为可选参数：reserve默认false，如果设置为true，则保留当前画布上的内容；callback是一个函数，表示绘制完成后回调。 Both are optional: reserve defaults to false. If set to true, it preserves the current canvas content; callback is a function called after drawing completes.

交互 Interaction

由于环境的特殊性，我们提供了跨端的方法来帮助你更简单的实现交互： Due to the special environment, we provide cross-platform methods to help you implement interaction more easily: 

    <ui-canvas @dotouchstart='doit'></ui-canvas>

其中doit是定义的方法： Where doit is the defined method: 

methods: {
    doit(region) {

        // {"name":string,"x":number,"y":number}
        console.log(region)
    }
}

在你每次点击画笔的时候就会触发doit方法，此方法有一个行参，记录着你点击的区域信息。 The doit method is triggered each time you click on the painter. This method has a parameter that records the area information you clicked.

引入 Import 

import { getLoopColors } from "vislite"

语法 Syntax

获取一组循环色彩： Get a set of looping colors: 

let colors = getLoopColors(num, alpha=1)

基础色 Base Colors

默认循环色基础颜色为（透明度可以修改）： Default looping base colors (opacity can be modified): 

    ['#5470c6', '#91cc75', '#fac858', '#ee6666', '#73c0de', '#3ba272', '#fc8452', '#9a60b4', '#ea7ccc']

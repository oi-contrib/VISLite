VISLite 能做什么？

VISLite 是一个轻量级的数据可视化前端库。我们的目标是帮助你更快速、简单、高效地开发各种可视化业务产品。

虽然这并非易事，但我们会持续完善和改进，为你提供更好的开发体验。

非常希望获得你宝贵的建议和批评，无论任何想法，都可以给我们 留言 告诉我们。

常用可视化算法

我们提供了多种可视化常用算法，帮助你轻松绘制复杂图表。例如树图，通过简单配置即可将任意格式的数据转换为带有坐标信息的可绘制数据：

上述例子的运行地址： 从左到右树状图 。

除了 树布局 外，我们还提供： 刻度尺算法 用于计算刻度位置、 等角斜方位投影 和 墨卡托投影 用于地图绘制、 Cardinal 插值函数 用于将折线转换为平滑曲线、 变换矩阵 用于各种坐标变换等。

增强的画笔能力

我们对画笔进行了增强，使其更加简单易用。例如 Canvas 抽象了区域概念，无论你绘制的图形多么不规则，都可以轻松实现交互功能：

上述例子的运行地址： 中国地图 。

画笔除了为方便交互而补充区域设计外，还对原有 API 进行了抽象，使其更加友好简单 （例如 SVG，你无需记忆那些晦涩难懂的属性，用直观的方式使用即可） 。同时，我们还抹平了不同浏览器版本之间的差异。

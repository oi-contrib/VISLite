类型不对 Type Mismatch

比如我们有如下代码： For example, we have the following code: 

let painter= new Canvas(el)

let config = {
  arcEndCap : "butt"
}

painter.config(config)

此时，我们可能会在定义的地方看见错误提示： At this point, we may see the following error:

Argument of type '{ arcEndCap: string; }' is not assignable to parameter of type 'CanvasConfigType'.

这是因为类型检查认为"butt"是字符串类型，其实我们要求的是： This is because type checking considers "butt" as a string type, but we actually require: 

    export type arcCapType = "butt" | "round" | "-round"

怎么办？最简单的就是声明成常量，需要改造的部分如下： What to do? The simplest way is to declare it as a constant: 

let config = {
    arcEndCap : "butt" as const
}

树布局 Tree Layout

基础用法 Basic Usage

首先，我们需要创建布局对象，并配置意图： First, we need to create a layout object and configure it: 

import { TreeLayout } from 'vislite';

// 创建布局对象
var treeLayout = new TreeLayout();

// 配置意图
treeLayout.setOption({
    type: "rect",
    direction: "TB",
    x: 250,
    y: 20,
    width: 500,
    height: 260
});

我们这里想绘制一个从上往下的树，大小为500*260，所以根在顶部中心，也就是(250,20)。 We want to draw a top-to-bottom tree with size 500*260, so the root is at the top center, which is (250, 20).

温馨提示：为什么根的位置不是(250,0)？这是因为结点是个球，球心稍微下一点，不然绘制不全。 Note: Why isn't the root position (250,0)? Because the node is a circle, the center is slightly lower, otherwise it wouldn't be drawn completely.

然后我们就可以把需要的数据变成方便绘图的格式了： Then we can convert the data into a format suitable for drawing: 

var data = {
    "name": "前端",
    "children": [{
        "name": "基础",
        "children": [{
            "name": "HTML"
        }, {
            "name": "CSS"
        }, {
            "name": "JavaScript"
        }, {
            "name": "DOM"
        }]
    }, {
        "name": "框架"
    }, {
        "name": "小技术"
    }]
};

var tree = treeLayout.use(data);

这里的tree就是我们要的绘图数据，看一下内容： The tree variable contains the drawing data we need. Let's check its content:

可以看到，这是一个json，其中有个属性node，里面包含了所有结点的信息，其中最重要的就是left和top，表示当前结点的位置。 As you can see, it's a JSON object with a `node` property containing all node information. The most important properties are `left` and `top`, which represent the position of each node.

那么我们应该怎么样？是的，把一个个结点按照这个位置绘制出来（也就是一个个小球）： So what should we do? Yes, draw each node at its position (as small circles): 

for (var key in tree.node) {
    painter.fullCircle(tree.node[key].left, tree.node[key].top, 10);
}

当然，为了好看，你应该在小球旁边画上结点名称、然后把自己和父结点连接起来。 Of course, for better visualization, you should draw the node names next to the circles and connect each node with its parent.

温馨提示：通过pid就知道自己的父结点是谁了，如果pid=null，说明是根结点，没有父结点，自然什么也不用做。 Note: Through pid you can know who your parent node is. If pid=null, it's the root node, no parent node, so nothing to do.

添加交互 Add Interaction

因为是需要交互（也就是点击结点可以控制孩子结点显示和隐藏），我们就不能直接使用返回的数据tree来绘制了，而是需要告诉布局如何绘制，如何告诉？如下： Since we need interaction (clicking a node to show/hide its children), we cannot directly use the returned tree data for drawing. Instead, we need to tell the layout how to draw. Here's how: 

treeLayout.bind(data, function (tree) {
    // todo
});

第二个参数的写法和上面的类似，只不过有一点不同：你需要判断当前结点是否应该显示。如何判断？ The second parameter is similar to the previous usage, but with one difference: you need to determine whether each node should be displayed. How?

非常幸运的是，我们提供了两个属性来告诉你当前结点显示情况（可以上滑一下看看上面的数据截图）： Fortunately, we provide two properties to indicate the display status of each node: isOpen来记录当前结点的孩子结点是否显示，show来记录当前结点是否显示 `isOpen` records whether the children of the current node are displayed, and `show` records whether the current node itself is displayed 。

所以你在具体绘制的时候，需要多些判断，别的也就并无差别了。 So when drawing, you just need to add these checks. Everything else remains the same.

聪明的你肯定可以猜到，默认这两个属性一定都是true，那如果我们可以动态修改它们的值，然后布局重新绘制，不就实现了交互了吗，是的，我们也是这样想的，因此提供了一个结点的孩子显示隐藏的方法： Smart you must have guessed that both properties default to true. If we can dynamically modify their values and redraw the layout, we can achieve interaction. Yes, that's exactly what we thought. Therefore, we provide a method to toggle the visibility of a node's children: 

    treeLayout.toggleNode(id);

其中id就是需要显示隐藏孩子结点的结点id。 Where `id` is the ID of the node whose children you want to show/hide.

当然，我们这里是用canvas绘制的，所以最终控制代码应该如下： Since we're using Canvas for drawing, the final control code should be as follows:

温馨提示：绘制的时候，别忘了记录区域哦~ Note: When drawing, don't forget to record regions~ 
el.addEventListener('click', function (event) {
    painter.getRegion(event.offsetX, event.offsetY).then(function (regionName) {
        if (regionName) {
            treeLayout.toggleNode(regionName);
        }
    });
});

特殊数据格式 Special Data Format

你可能会想，我们用来绘图的原始数据，一定要按照例子的给出吗？答案当然是否定的，比如我们现在的原始数据如下： You might wonder if the raw data must follow the example format. The answer is no. For example, our raw data could be as follows: 

var data = [
    // 结点名称、父节点名称
    ["手绘", null],
    ["水粉", "手绘"],
    ["油画", "手绘"],
    ['题材', '油画'],
    ['画法', '油画'],
    ["素描", "手绘"],
    ["中国画", "手绘"],
    ["空间透视", "素描"],
    ["色彩五大调", "素描"]
];

怎么办？我们只需要在创建布局的时候告诉布局对象我们的数据格式如何解析即可： What to do? We just need to tell the layout object how to parse our data format when creating it: 

var treeLayout = new TreeLayout({

    // 根结点是谁
    // who is the root node
    root: function (initTree) {
        return initTree[0];
    },

    // 已知当前结点，如何知道它的孩子结点是谁
    // given current node, how to know its children
    children: function (parentTree, initTree) {
        var children = [];
        for (var i = 0; i < initTree.length; i++) {
            if (initTree[i][1] == parentTree[0])
                children.push(initTree[i]);
        }
        return children;
    },

    // 当前结点的id如何生成
    // how to generate id for current node
    id: function (initTree) {
        return initTree[0];
    }
});

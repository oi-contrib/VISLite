基本使用 Basic Usage

准备画布 Prepare Canvas

使用之前，我们首先需要准备一个设置了大小的节点，具体是用的div还是span或者别的都可以： Before using, we need to prepare a node with size set. It can be a div, span or other elements: 

<div id="mycanvas" style="width:300px;height:300px;"></div>

获取画笔 Get Painter

准备好节点以后，就可以获取画笔了： After preparing the node, we can get the painter: 

import { Canvas } from 'vislite';

var painter = new Canvas(document.getElementById('mycanvas'));

绘制 Drawing

现在，画笔也有了，我们就可以直接用这支画笔绘制我们想要的内容了。 Now that we have the painter, we can directly draw what we want.

比如我们想在 (50, 20)处 写段文字，然后在 (150, 150)处 绘制一个 半径100 的小球： For example, we want to write some text at (50, 20) and then draw a small ball with a radius of 100 at (150, 150): 

painter.fillText("我爱你，中国～", 50, 20);
painter.fillCircle(150, 150, 100);

当然，画笔的属性也是可以修改的，比如你可以设置小球的颜色： Of course, you can modify the painter's properties, such as setting the circle color: 

painter.config({
    "fillStyle": "pink"

虽然你可以通过点击的位置，然后结合具体的图表，使用数学运算等来判断。比如通过计算到球心的位置来判断是否点击了某个小球，结合sin和cos就可以进一步判断弧形等，可是，这不能很好的解决下列问题： Although you can determine by click position combined with specific charts using mathematical calculations. For example, calculate the distance to the center to determine if a circle is clicked, use sin and cos to further determine arcs, etc., this cannot solve the following problems well:

反馈 Feedback

比如我们给画布添加一个点击事件，用来告诉我们点击的是谁： For example, we add a click event to the canvas to tell us which element is clicked: 

el.addEventListener('click', function (event) {
    painter.getRegion(event.offsetX, event.offsetY).then(function (index) {
        if (index) {
            alert("点击的区域编号：" + index);
        }
    });
});

这里的 The index 和前面 here is the same as the value passed to painter.setRegion(i + 1) 传递的值是一样的（如果点击的不是区域，那就统一是空字符串）。 (if clicking outside a region, it returns an empty string).

悬浮提示 Tooltip

现在我们已经从技术上解决了交互的问题，那么，我们就进一步演示一下如何添加悬浮提示。 Now that we have solved the interaction problem technically, let's further demonstrate how to add tooltips.

悬浮提示本质上来说就是：根据鼠标的位置来判断悬浮框此时是否显示，以及显示的内容和位置。我们推荐使用div作为悬浮框，这样好控制： Essentially, a tooltip determines whether to show based on mouse position, and controls its content and position. We recommend using a div as the tooltip container for better control:

针对小程序或者uni-app等，改成view标签后使用对应语法修改也类似。 For mini programs or uni-app, changing to view tag and using corresponding syntax is similar. 
<div id="tooltip" class="tooltip"></div>

一般来说，悬浮提示触发的事件是鼠标移动，那么，js部分大概如下： Generally, tooltips are triggered by mouse movement. The JS code is roughly as follows: 

el.addEventListener('mousemove', function (event) {
    painter.getRegion(event.offsetX, event.offsetY).then(function (index) {
        if (!index) {
           // 隐藏悬浮框
           // hide tooltip
        }else{
           // 显示悬浮框，并修改内容和位置
           // show tooltip and update content and position
        }
    });
});

当然，我们还需要添加css来美化悬浮框的样式，进一步，还可以借助transition优化悬浮框位置改变时候的动画效果，因为这些都属于css基础知识，这里就不再赘述了。 Of course, we need to add CSS to style the tooltip. Additionally, we can use transitions to optimize the animation when the tooltip position changes. Since these are basic CSS knowledge, we won't elaborate here.

基本使用 Basic Usage

准备画布 Prepare Canvas

使用之前，我们首先需要准备一个设置了大小的节点，具体是用的div还是span或者别的都可以： Before using, we need to prepare a node with size set. It can be a div, span or other elements: 

<div id="mywebgl" style="width:300px;height:300px;"></div>

获取画笔 Get Painter

准备好节点以后，就可以获取画笔了： After preparing the node, we can get the painter: 

import { getWebGLContext } from 'vislite';
var painter = getWebGLContext(document.getElementById('mywebgl'));

画笔有了，是不是直接调用画笔上的方法就可以绘制了？非常遗憾，不可以，我们还需要在绘制前准备好绘制程序，我们称为 Now that we have the painter, can we draw directly by calling methods on it? Unfortunately no, we still need to prepare the drawing program before drawing, which we call 着色器 。 shader .

简单的理解：着色器是一种独立在GPU中，仅将输入处理后再输出的程序，此处的着色器，其采用 Simply put: A shader is a program that runs independently on the GPU and only processes inputs before outputting. This shader uses GLSL ES 语言编写的，和C语言非常类似（如果你对此感兴趣，可以 language, which is very similar to C language (if you are interested, you can 给我们留言 leave us a message ，我们将展开说明）。 and we will explain in detail).

定义着色器程序 Define Shader Program

描述点的位置（或大小）的称为顶点着色器，描述点的色彩的称为片段着色器。下面先来看看这里的具体代码： The shader that describes the position (or size) of points is called vertex shader, and the shader that describes the color of points is called fragment shader. Let's first look at the specific code here:

顶点着色器 Vertex Shader 

<script type='x-shader/x-vertex' id='vs'>
attribute vec4 a_position;

void main(){
    gl_Position = a_position;
}
</script>

片段着色器 Fragment Shader 

<script type='x-shader/x-fragment' id='fs'>
precision mediump float;
uniform vec4 u_color;

void main(){
    gl_FragColor = u_color;
}
</script>

编译并生效 Compile and Activate

本质上来说，这里其实就是两段字符串（也就是源码），直接编译成着色器程序并生效即可： Essentially, these are two strings of source code that are directly compiled into a shader program and activated: 

import { Shader} from 'vislite';

var shader = new Shader(painter).compile(
    document.getElementById("vs").innerText,
    document.getElementById("fs").innerText
).use();

现在，着色器程序也准备好了，是不是真的可以开始绘制了？只能再次说：不可以！我们还需要为这个着色器程序准备好数据。 Now that the shader program is ready, can we really start drawing? Unfortunately no! We still need to prepare data for this shader program.

设置数据 Set Data

设置数据的第一步是：确定需要设置哪些数据。根据上面的着色器代码可以发现，需要的数据如下： The first step in setting data is to determine what data needs to be set. According to the shader code above, the required data is:

  • u_color：uniform vec4 类型，用于设置物体颜色； type, used to set object color;
  • a_position：attribute vec4 类型，用于设置物体点的位置。 type, used to set object point position.

知道应该设置哪些数据后，那就需要知道如何设置了。 Now that we know what data to set, we need to know how to set it.

设置单个数据 Set Single Data

被uniform修饰的变量，只需要设置单一的数据，比如这里的 Variables modified by uniform only need single data, like the u_color 变量。 variable here.

画笔painter上就提供了相关方法，你可以 The painter provides related methods, you can ，这里直接看具体代码： . Here is the specific code: 

var location = painter.getUniformLocation(shader.program, "u_color");
painter.uniform4f(location, 1, 0, 0, 1);

类型是 The type is uniform ，所以使用 , so we use getUniformLocation() 方法获取位置。 method to get the location.

然后设置的时候发现其数据类型是 Then when setting, we see its data type is vec4 ，也就是4分量浮点向量，所以再使用 , which is a 4-component floating-point vector, so we use uniform4f() 方法在获取的位置上设置数据，也就是完成了对u_color的数据设置。 method to set data at the obtained location, which completes the data setting for u_color.

设置多个数据 Set Multiple Data

被attribute修饰的变量，需要设置多个数据，也就是需要使用缓冲区。 Variables modified by attribute need to set multiple data, which requires using buffers.

使用缓冲区的第一步当然是创建缓冲区对象了： The first step in using buffer is of course to create a buffer object: 

var buffer = new Buffer(painter).use().write(new Float32Array([
    -0.5, 0.5, 0,
    0.5, 0.5, 0,
    -0.5, -0.5, 0
]));

上面代码的意思简单描述就是：创建好以后调用 The meaning of the above code is simply: after creating, call use() 方法表示现在使用这个缓冲区，最后，往缓冲区中写入数据。 method to indicate using this buffer now, and finally write data to the buffer.

现在，缓冲区里面有数据了，可是我们是需要数据设置给变量a_position的呀，怎么办？当然是调用缓冲区上的 Now the buffer has data, but we need to set data to the a_position variable. What to do? Of course call the divide() 进行分配（实际情况是，缓冲区的数据可能给多个变量，所以需要分一下）： method on the buffer to distribute (in reality, buffer data may be given to multiple variables, so it needs to be divided): 

var location = painter.getAttribLocation(shader.program, "a_position");
buffer.divide(location, 3, 3, 0);

上面的第一句获取变量位置应该不陌生了，我们来说明一下第二句。 Getting the variable location in the first line should be familiar. Let us explain the second line.

首先，divide方法的第一个参数表示需要分配变量的位置，第二个参数表示一个变量的长度，点的位置xyz，所以是3（如果考虑齐次长度也可以是4，这也是为什么数据类型是vec4）。 First, the first parameter of divide method represents the location of the variable to be assigned, the second parameter represents the length of one variable. The point position is xyz, so it's 3 (considering homogeneous length it can also be 4, which is why the data type is vec4).

那第三个参数为什么也是3？在只给一个变量分配的时候，这个参数基本和第二个参数一致，而如果有多个变量就不一样了，你可以简单的理解这个表示所有变量长度和。 Why is the third parameter also 3? When only one variable is assigned, this parameter is basically the same as the second parameter. If there are multiple variables, it's different. You can simply understand this as the sum of all variable lengths.

最后一个参数表示分配偏移，如果只有一个参数，基本就是0，而如果有多个，比如三个参数，长度分别是3、2、3，那么基本上给这三个变量分配的时候最后一个参数分别应该是0、3、5。 The last parameter represents the allocation offset. If there is only one parameter, it's basically 0. If there are multiple, for example three parameters with lengths 3, 2, 3, then when assigning to these three variables, the last parameter should be 0, 3, 5 respectively.

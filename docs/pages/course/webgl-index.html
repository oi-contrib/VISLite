使用索引 Using Index

基础点 Basic Points

首先，和非索引写法类似的设置所有未重复的点： First, set all non-repeated points similar to the non-indexed writing: 

var buffer = new Buffer(painter).use().write(new Float32Array([
    -0.4, 0.4, 0,
    0.5, 0.5, 0,
    -0.5, -0.5, 0,
    0.4, -0.4, 0,
]));

没有重复的点一共四个，第四和第五个点和前面的重复了，删除掉。 There are four non-repeated points. The fourth and fifth points are duplicates of the previous ones, so we delete them.

定义点 Define Points

不同于普通的点坐标，借助索引缓冲区可以基于普通点来"丰富出"更多的点，先看这里的代码： Unlike ordinary point coordinates, using index buffer can "enrich" more points based on ordinary points. First look at the code here: 

new Buffer(painter, true).use()
    .write(new Uint8Array([
        0, 1, 2,
        1, 2, 3
    ]));

前面的三个数据表示一个点，这里不同，这里一个数据表示一个点，比如第一个点值是0，就表示前面设置的普通点中的第一个点作为这里的第一个点，以此类推。 The previous three data represent one point, but here it's different. Here one data represents one point. For example, the first point value is 0, which means the first point of the previously set ordinary points is used as the first point here, and so on.

绘制 Drawing

因为点来自索引缓冲区，所以画笔需要使用索引方法： Because points come from the index buffer, the painter needs to use the index method: 

    painter.drawElements(painter.TRIANGLES, 6, painter.UNSIGNED_BYTE, 0);

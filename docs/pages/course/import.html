如何引入？ How to Import?

安装 Installation

首先，你需要使用npm安装此包： First, you need to install this package using npm: 

npm install --save vislite

全量引入 Full Import

也就是引入后可以通过把柄VISLite来调用其上的方法： After importing, you can call methods through VISLite:

ES Module ES Module 

import VISLite from 'vislite'

当然，也可以指明具体的内容，比如： Of course, you can also specify specific content, for example: 

import { Example } from 'vislite'
温馨提示：上面的Example只是一个占位符，使用的时候应该换成具体的，比如Canvas、SVG、rotate、Matrix4等，下同。 Note: Example above is just a placeholder. Replace it with actual names like Canvas, SVG, rotate, Matrix4, etc. Same below.

按需引入 Partial Import

在大部分情况下，你可能不会用到所有能力，所以全量引入并不总是一个好的选择： In most cases, you may not need all features, so full import is not always a good choice: 

import Example from "vislite/lib/Example/index.es.min.js"

TypeScript 源码引入 TypeScript Source Import

如果你希望直接引入源码使用而不是打包后的js文件，你可以： If you want to import source code directly instead of bundled JS files:

全量引入 Full Import 

import VISLite from 'vislite/package/index'
温馨提示：这要求你的项目配置了TypeScript解析相关内容。 Note: This requires your project to be configured with TypeScript resolution.

按需引入 Partial Import

同样的，按需引入例子： Similarly, partial import example: 

import Example from "vislite/package/Example/index"
